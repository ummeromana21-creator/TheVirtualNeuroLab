Lab notebook

A complete record of every experiment the lab has run: the question, why it matters, exactly how it was done, the pass mark and when it was written down, every result (misses included), what we conclude, how sure we are, and whether it points to a discovery.

How every record is kept
  • The pass mark is written down before the run, with a timestamp, so it can't be moved after seeing the answer.
  • Nothing is tuned. Every run uses the published brain model and settings, unchanged.
  • Every result is reported, including misses, and a miss is explained only by what the data show.
  • Each record is built from the lab's result files, not typed in by hand, and lists the files so anyone can check them.

How sure are we?

Every prediction gets a confidence level from two questions answered by its own data, and one fact about the model that applies to all of them.

  1. Is the effect clear in the simulation? Each prediction was run 30 times with random input. We measure how much the result varies between runs and give a 95% range. If the whole range stays above the 20% "needed" line, the effect is clear.
  2. How big is it? A drop of 50% or more is large; 20-50% is moderate.
  3. How good is the model at this kind of question?
